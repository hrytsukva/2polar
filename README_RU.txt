МОЁ СОСТОЯНИЕ — стартовый проект PWA
=====================================

Что уже работает в этом прототипе:
- локальная база данных IndexedDB в браузере iPhone;
- список лекарств с названием, временем и периодичностью;
- записи настроения 0–5;
- учёт сна, качества и нескольких ночных пробуждений;
- дневник с отдельным полем для приснившегося сна;
- фильтр дневника по датам;
- конструктор собственных наблюдений по трём фазам;
- экспорт каждого раздела в CSV (открывается в Excel);
- общая резервная копия JSON;
- кэширование оболочки для офлайн-работы.

ВАЖНО:
Это начальный рабочий каркас, не законченная медицинская система.
Пока не реализованы:
- автоматические уведомления и экспорт расписания в календарь (.ics);
- полноценный XLSX;
- импорт/восстановление резервной копии;
- редактирование уже сохранённых записей;
- защита Face ID (для PWA это ограничено возможностями iOS).

КАК ОТКРЫТЬ НА WINDOWS:
1. Распакуйте архив.
2. Для теста можно открыть index.html двойным щелчком, но офлайн-кэш и установка PWA так не заработают.
3. Для полноценной установки PWA проект нужно разместить на HTTPS-хостинге.
   Бесплатный вариант: GitHub Pages.
4. Создайте бесплатный аккаунт GitHub, новый публичный репозиторий и загрузите
   содержимое этой папки в корень репозитория.
5. В репозитории откройте Settings → Pages.
6. В разделе Build and deployment выберите Deploy from a branch,
   ветка main, папка /(root), затем Save.
7. GitHub выдаст HTTPS-адрес сайта. Откройте его в Safari на iPhone.
8. Нажмите Поделиться → На экран «Домой» → Добавить.
9. Откройте установленное приложение один раз при наличии интернета.
   Затем проверьте работу в авиарежиме.

ПРЕДУПРЕЖДЕНИЕ О ДАННЫХ:
Данные IndexedDB хранятся локально в профиле установленного веб-приложения.
Не очищайте данные Safari/сайта и не удаляйте приложение, пока не сделали
резервную копию. Резервная копия JSON пока только скачивается; восстановление
из неё будет добавлено отдельным этапом.

УВЕДОМЛЕНИЯ:
iOS ограничивает возможности веб-приложений. В этом проекте уведомления ещё
не реализованы. Следующим шагом добавим экспорт расписания в календарь (.ics),
чтобы системные напоминания iPhone срабатывали независимо от интернета.


ОБНОВЛЕНИЕ 2

В этой версии добавлены:
- расписание лекарств до 3 приёмов в день: утро, обед, вечер; время напоминания необязательно;
- отметки о приёме на текущую дату;
- экспорт напоминаний в .ics для импорта в календарь iPhone;
- шкала настроения 0–5 с текстовыми значениями;
- интервалы ночных пробуждений (время пробуждения и повторного засыпания);
- таблица сфер по пяти состояниям и история изменений;
- общая книга Excel XML (.xls) с отдельными листами разделов;
- восстановление из JSON-резервной копии.

ВАЖНО О ФОРМАТЕ EXCEL
Общая книга использует Excel XML 2003 (.xls), а не современный .xlsx. Она содержит несколько листов и открывается в Microsoft Excel. После открытия её можно сохранить в формате .xlsx через «Сохранить как».

РЕЗЕРВНОЕ КОПИРОВАНИЕ
В разделе «Экспорт» нажми «Скачать резервную копию всех данных». Сохрани JSON-файл отдельно от телефона: например, на компьютере или внешнем носителе. Для восстановления открой тот же раздел, выбери файл в поле «Восстановить данные». Восстановление заменяет текущие данные содержимым копии.
Автоматически сохранять копию в отдельное место без твоего действия приложение не может: браузер iPhone не разрешает сайту незаметно записывать файлы в произвольные папки. Поэтому делай копию регулярно.

НАПОМИНАНИЯ
Само PWA не может надёжно показывать локальные уведомления, когда закрыто на iPhone. Для этого версия экспортирует .ics: открой файл на iPhone и добавь события в календарь. Проверь, что для календаря разрешены уведомления. Если меняешь расписание препарата, экспортируй и импортируй обновлённые события; старые события в календаре нужно удалить вручную.

ОБНОВЛЕНИЕ УЖЕ ОПУБЛИКОВАННОГО САЙТА
Загрузи новые версии index.html, app.js, styles.css и sw.js в корень репозитория GitHub, соглашаясь на замену файлов, затем Commit changes. При следующем открытии сайта обновится оболочка приложения. Данные IndexedDB остаются на устройстве; всё равно скачай резервную копию перед обновлением.


Версия 4: добавлена быстрая отметка лекарств на главной, сворачиваемые таблицы препаратов, трёхуровневые шкалы дополнительных ощущений, история оценок критичности с фазой на дату оценки, раздел целей и подцелей. Для обновления сначала скачайте резервную копию JSON. База IndexedDB автоматически обновляется до версии 4; новые записи хранятся локально.


ИЗМЕНЕНИЯ В ВЕРСИИ 8
- Основа приложения сохранена из версии 5; имя и версия базы IndexedDB не изменены.
- Добавлены локальный выбор валюты целей (EUR/PLN/RUB), ветки подцелей и кнопки редактирования.
- Добавлена локализация RU/PL/EN статического и динамически создаваемого интерфейса.
- На главной добавлены настройки отображения разделов в верхней навигации; Экспорт всегда доступен.
- Добавлено однократное подтверждение возраста 18+ и согласие с условиями использования.
- Экспорт формирует ссылку на скачивание, если автоматическая загрузка браузером не сработала.
- Импорт JSON проверяет структуру файла до начала транзакции и ждёт подтверждения завершения транзакции.
